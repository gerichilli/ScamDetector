# Labeling Guideline

## Labels

### SCAM

Use SCAM when the message clearly contains scam signals, such as:

- Asking for OTP, password, verification code
- Asking for urgent money transfer
- Impersonating police, court, bank, or official organization
- Asking the user to click suspicious links
- Claiming prize/gift and asking for fee or personal information
- Promising abnormal investment profit
- Asking the user not to tell relatives

### SUSPICIOUS

Use SUSPICIOUS when the message has unclear or partial risk signals, such as:

- Asking to verify account but no direct OTP request
- Mentioning account issue without clear source
- Asking for personal information but context is unclear
- Sending a link without enough information
- Introducing investment/job/loan opportunity without direct payment request

### SAFE

Use SAFE when the message is normal or does not ask for sensitive actions, such as:

- Family conversation
- Normal reminder
- Delivery/order notice without suspicious link
- Bank maintenance announcement without asking for OTP/link/password
- Money transfer in safe personal context

## Important Notes

- Do not include real phone numbers, bank accounts, names, addresses, or real victim details.
- Use placeholders such as <PHONE>, <BANK_ACCOUNT>, <LINK>, <OTP>, <NAME>.
- Region and noise metadata are only used for fairness/robustness evaluation, not as decision features.
